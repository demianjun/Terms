# 特定商取引法に基づく表記

**最終改定日:** 2026年9月13日

| 項目 | 内容 |
|---|---|
| 販売事業者 | DreamAppLab。法的氏名は、請求があった場合、購入申込み前に遅滞なく開示します |
| 運営責任者 | 請求があった場合、購入申込み前に遅滞なく開示します |
| 所在地・電話番号 | 請求があった場合、購入申込み前に遅滞なく開示します。下記メールアドレスからご請求ください |
| 問い合わせ先 | [demianjun1@gmail.com](mailto:demianjun1@gmail.com) |
| 販売商品 | 広告削除（非消耗型App内課金） |
| 販売価格 | 購入画面に表示される金額。表示価格には適用される税を含みます |
| 商品代金以外の費用 | インターネット接続料金および通信料金は利用者の負担となります |
| 支払方法 | Apple IDに設定された支払方法を通じてAppleが決済します |
| 支払時期 | 購入確定時に課金されます |
| 提供時期 | App Storeでの決済および取引検証完了後、原則として直ちに広告削除機能が有効になります |
| 返品・キャンセル | デジタル商品の性質上、提供開始後の返品・交換は受け付けません。ただし、適用法令により認められる場合を除きます。取消し・返金はAppleの手続に従います |
| 購入の復元 | アプリ内の「購入を復元」から、同一のApple IDに紐づく購入を復元できます |
| 対応環境 | iOS 18以降。対応するiPhoneまたはiPad、インターネット接続および有効なApple IDが必要です |
| その他の条件 | 広告削除は自動更新サブスクリプションではありません。利用権限はStoreKitで検証された取引を基準とします |

返金を希望する場合は、Appleの[返金手続](https://support.apple.com/ja-jp/118223)をご確認ください。
