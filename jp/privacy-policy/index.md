## 3. 取り扱う情報

本サービスは、利用方法に応じて次の情報を取り扱います。

| 区分 | 情報 | 利用目的 |
|---|---|---|
| 端末内の目標・記録 | 目標名、難易度、開始日、期間、リマインダー時刻、日次達成記録、再開履歴 | 目標管理、進捗表示、リマインダーおよび再開機能の提供 |
| 端末内の設定 | 言語、テーマ、通知、表示、4桁PIN、広告削除状態 | 利用者設定、端末内ロックおよび購入状態表示の提供 |
| Appleでサインイン | Appleユーザー識別子、メールアドレス（公開メールまたは非公開メールの中継アドレス） | ログイン、本人確認およびアカウント連携 |
| Googleでサインイン | Googleアカウント識別子、メールアドレス、氏名、プロフィール画像URL（提供される場合） | ログイン、本人確認およびアカウント連携 |
| Firebase Authentication | Firebase UID、認証プロバイダおよび認証状態 | 認証およびアカウント管理 |
| Cloud Firestore | 同期対象の目標・日次記録・再開情報、広告削除状態および購入日、更新時刻、削除状態 | 複数端末間の同期およびデータ復元 |
| App内課金 | 商品識別子、取引識別子、購入日、検証済み利用権限 | 広告削除商品の提供、検証および購入復元 |
| 広告・同意情報 | IPアドレス、端末・OS・アプリ情報、広告関連識別子（利用可能な場合）、広告の表示・操作・診断情報、同意状態 | 広告配信、効果測定、不正防止、同意管理および障害対応 |
| Firebase App Check | アプリおよび端末の正当性を検証するトークン・技術情報 | 不正なサーバーアクセスの防止 |

アカウントに接続しない場合、目標・記録は原則として端末内に保存され、Cloud Firestoreには同期されません。本サービスは、カード番号その他の決済手段情報やFace IDの顔情報を直接取得・保存しません。Face IDの照合はiOSが行い、本サービスは認証結果のみを受け取ります。

本サービスは、Google Mobile Ads SDKを利用して広告を表示する場合があります。また、Google User Messaging Platformを使用し、必要な地域で同意を取得してプライバシー選択肢を提供します。

本バージョンはApp Tracking Transparency（ATT）の許可を要求せず、IDFAを利用したアプリ間トラッキングを行いません。同意状態、地域および端末設定に応じて、非パーソナライズ広告または制限付き広告が表示される場合があります。

広告に関する選択方法は、[プライバシー設定]({{ site.baseurl }}/ja/privacy-choices/)および[外部送信について]({{ site.baseurl }}/ja/external-transmission/)をご確認ください。

## 9. 保存期間と削除

| 保存場所・情報 | 保存期間・削除方法 |
|---|---|
| 端末内の目標・記録 | 利用者が対象データまたはアプリデータを削除するまで |
| UserDefaultsの設定 | 利用者が設定またはアプリデータを削除するまで |
| KeychainのPIN・セッション情報 | 機能の解除、明示的な削除またはiOSによる削除まで。再インストール後も残る場合があります |
| Firebase AuthenticationおよびCloud Firestore | アカウント削除まで。削除手続完了後、法令上保存が必要な場合を除き遅滞なく削除します |
| App Storeの購入・取引記録 | Appleのポリシーおよび適用法令に従う期間 |
| 広告・診断情報 | Googleのポリシーおよび適用法令に従う期間 |

アプリ内でアカウントを削除すると、Firebase Authenticationのアカウントおよび当該アカウントに関連付けられたCloud Firestore上のデータを削除します。ログアウトだけではサーバーデータは削除されません。

アカウントを削除しても、この端末に保存された目標・記録は自動的には削除されません。端末内データは利用者が別途削除するか、アプリデータを削除するまで保持されます。App Storeの購入履歴はAppleが管理します。
